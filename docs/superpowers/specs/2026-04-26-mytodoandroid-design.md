# MyTODOAndroid 设计文档

## 1. 项目目标

构建一个安卓原生 TODO 应用 `MyTODOAndroid`，参考现有 Windows 版 MyTODO 的核心任务管理能力，但针对安卓端重新设计交互，符合手机使用习惯，并重点支持桌面小组件快速完成今日任务。

本项目不与 Windows 端同步，数据完全本地存储。

## 2. 范围定义

### 保留功能
- 今日待办首页
- 父任务 / 子任务结构
- 任务完成 / 取消完成
- 重复规则：
  - 不重复
  - 每日
  - 每周
  - 每 X 天
  - 指定日期
- 日期信息展示
- 农历 / 节日信息展示
- 桌面小组件显示今日待办
- 在桌面小组件中直接勾选完成 / 取消完成

### 移除功能
- 备忘录
- 拓展区域
- 长期待办
- Windows 端同步
- 优先级颜色
- 深色模式

## 3. 技术方案

### 3.1 技术栈
- 语言：Kotlin
- UI：Jetpack Compose
- 本地数据库：Room
- 状态管理：ViewModel + StateFlow
- 桌面小组件：Glance + AppWidget
- 日期逻辑：java.time
- 农历 / 节日：引入适合 Android 的农历计算库，或在项目内封装稳定的本地农历计算能力

### 3.2 选择原因
原生 Android + Jetpack Compose 是本项目的最佳方案，原因如下：
- 小组件能力最强，能稳定支持桌面任务勾选
- 更贴合安卓和小米 13 的使用体验
- 本地数据库与系统组件联动简单可靠
- 后续适配通知、快捷入口、设置页等扩展能力更自然

## 4. 核心信息架构

### 4.1 App 首页结构
首页采用“只看今天”的结构。

页面从上到下为：
1. 顶部标题区
   - 标题：今日待办
   - 日期：公历日期 + 星期
   - 辅助信息：农历日期 / 节日文案
2. 今日任务进度区
   - 已完成数量 / 总数量
   - 简洁进度条
3. 今日任务列表
   - 按父任务和子任务树状展示
4. 悬浮新增按钮或顶部新增按钮
   - 点击后打开底部表单

首页默认只显示“今天需要执行的任务”，不以全量任务总览作为主入口。

### 4.2 新建 / 编辑任务入口
采用 Bottom Sheet 表单，便于单手操作。

表单字段：
- 任务内容
- 是否包含子任务
- 子任务列表
- 重复方式
- 每周日期选择（仅每周模式显示）
- 间隔天数输入（仅每 X 天模式显示）
- 指定日期选择（仅指定日期模式显示）
- 截止日期（仅子任务或需要过期控制的任务使用）

## 5. 数据模型设计

### 5.1 TodoEntity
建议包含以下字段：

- `id: String`
- `content: String`
- `parentId: String?`
- `sortOrder: Int`
- `repeatMode: String`
- `weekdays: String?`
- `intervalDays: Int?`
- `specificDates: String?`
- `anchorDate: String?`
- `expiryDate: String?`
- `completed: Boolean`
- `completedAt: String?`
- `disabled: Boolean`
- `expanded: Boolean`
- `createdAt: Long`
- `updatedAt: Long`

### 5.2 字段说明
- `parentId`：为空表示父任务，否则表示子任务
- `repeatMode`：取值建议为 `none` / `daily` / `weekly` / `interval_days` / `specific_dates`
- `weekdays`：用逗号存储周几，例如 `1,3,5`
- `intervalDays`：每 X 天循环时的 X
- `specificDates`：存储指定日期列表，例如 `2026-04-26,2026-04-28`
- `anchorDate`：每 X 天循环的起始基准日期
- `expiryDate`：截止日期，过期后任务可自动禁用
- `expanded`：父任务在首页是否展开

## 6. 今日任务判定逻辑

### 6.1 不重复任务
- 若任务创建后未完成，则在今天显示
- 完成后不再显示

### 6.2 每日任务
- 每天显示
- 当天完成后标记为已完成
- 到下一天自动进入新周期并恢复未完成状态

### 6.3 每周任务
- 仅在选中的星期几显示
- 例如选周一和周三，则只在这些日期进入今日任务列表
- 每个匹配日拥有独立的当日完成状态

### 6.4 每 X 天任务
- 使用 `anchorDate` 作为起点
- 例如 `anchorDate = 2026-04-28`，`intervalDays = 2`
- 若 `today - anchorDate` 的天数差可被 2 整除，则今天显示该任务
- 当天完成只影响当前周期
- 下一个满足条件的日期重新显示为未完成

### 6.5 指定日期任务
- 仅在 `specificDates` 包含今天日期时显示
- 每个指定日期只对应一次执行机会

### 6.6 子任务逻辑
- 子任务默认跟随父任务是否进入今日列表
- 若父任务今天出现，其子任务一并展示
- 点击父任务完成时，需要先确认，再将全部子任务标记完成
- 子任务可单独勾选完成 / 取消完成

### 6.7 过期禁用逻辑
- 若任务设置了截止日期，且当前日期已超过截止日期，则自动禁用
- 禁用任务默认不出现在今日列表
- 若后续存在“任务管理页”，可以提供查看与重新启用能力

## 7. 完成状态设计

### 7.1 首页交互
- 每个任务右侧显示一个可点击方框
- 点击后立即切换：
  - 未完成 -> 已完成
  - 已完成 -> 未完成
- 任务完成后文字变灰，可加删除线
- 切换时使用轻量动画和轻微震动反馈

### 7.2 父任务完成
- 若父任务存在子任务，点击父任务勾选框时先弹出确认
- 用户确认后，将父任务和所有子任务一并标记完成

### 7.3 小组件完成
- 小组件上的右侧方框可直接点击
- 点击后后台写入数据库，并刷新小组件显示
- 不跳转 App
- 如果系统限制导致某些 ROM 下刷新延迟，优先保证状态正确，再通过 WorkManager 或组件刷新请求补齐更新

## 8. UI 设计原则

### 8.1 整体风格
- 固定浅色模式
- 风格偏小米 HyperOS：简洁、圆润、留白充足
- 页面背景使用浅灰白色
- 卡片使用纯白色
- 重点色使用偏系统感的蓝色

### 8.2 小米 13 适配重点
- 采用大圆角卡片与底部弹层
- 重要点击区域不小于 44dp
- 主要操作区域放在拇指容易触达的位置
- 字号层级清晰，保证日常快速扫读今日任务

### 8.3 首页视觉层级
- 顶部“今日待办”采用大标题
- 日期与农历信息作为次级视觉层
- 进度条位于标题区下方
- 任务列表为页面主内容
- 新增按钮保持稳定可见

## 9. 桌面小组件设计

### 9.1 尺寸
首版支持以下规格：
- 4x2：显示标题、进度、少量今日任务
- 4x3：显示更多任务

### 9.2 展示内容
- 顶部标题：今日待办
- 进度信息：例如 `3/5 已完成`
- 今日任务列表
- 每个任务右侧一个方框按钮

### 9.3 交互规则
- 点击任务右侧方框：直接切换完成状态
- 点击任务内容区域：打开 App 并定位到今日页
- 点击标题或空白区域：打开 App 首页

### 9.4 小组件限制与设计取舍
由于 Android 小组件交互能力有限，首版遵循以下原则：
- 小组件只做“查看今日任务 + 快速勾选完成”
- 不在小组件内支持复杂编辑
- 不在小组件内支持直接新增复杂任务
- 避免过度依赖动画与复杂手势

## 10. 页面清单

### 10.1 今日页
- 今日标题
- 日期 / 星期 / 农历 / 节日
- 今日进度
- 今日任务树
- 新增任务入口

### 10.2 新建 / 编辑任务页（Bottom Sheet）
- 任务内容输入
- 子任务编辑
- 重复方式选择
- 条件字段输入
- 保存 / 取消

### 10.3 设置页（精简）
首版设置页仅保留必要项：
- 小组件刷新说明
- 震动反馈开关
- 是否显示农历 / 节日

不加入复杂个性化配置。

## 11. 测试策略

### 11.1 单元测试
重点覆盖：
- 今日任务筛选逻辑
- 每周任务筛选逻辑
- 每 X 天逻辑
- 指定日期逻辑
- 父子任务完成逻辑
- 过期禁用逻辑

### 11.2 UI 测试
重点验证：
- 今日页打开速度与内容正确性
- 任务勾选与取消勾选
- 父任务确认完成流程
- Bottom Sheet 新建 / 编辑任务流程

### 11.3 小组件测试
重点验证：
- 小组件首次添加到桌面后的显示
- 勾选任务后数据库状态更新
- 勾选后小组件刷新
- 打开 App 后状态一致
- 小米 13 实机桌面适配效果

## 12. 非目标
以下内容不在首版实现范围内：
- Windows 与 Android 数据同步
- 云同步
- 长期待办
- 备忘录
- 拓展区
- 优先级系统
- 深色模式
- 桌面小组件内复杂编辑

## 13. 推荐实现顺序
1. 搭建原生 Android 项目骨架
2. 建立 Room 数据模型与 DAO
3. 实现今日任务筛选逻辑
4. 完成 Compose 今日页
5. 完成新增 / 编辑任务 Bottom Sheet
6. 实现父子任务交互
7. 接入农历 / 节日展示
8. 实现桌面小组件
9. 完成测试与小米 13 适配调整

## 14. 最终结论
MyTODOAndroid 将是一个面向安卓手机场景重新设计的轻量级本地 TODO 应用。它保留 Windows 版中真正高价值的任务调度能力，同时移除不适合手机端的功能，并把“桌面快速勾选今日任务”作为第一优先级体验来实现。
